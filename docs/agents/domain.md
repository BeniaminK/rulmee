# Domain Documentation: Single-context

This repository uses a single-context domain documentation layout.

## Documentation Structure

- Root context: `CONTEXT.md` at repo root.
- Architecture Decision Records (ADRs): `docs/adr/`.

## Consumer Rules

- Always consult `CONTEXT.md` before making architectural or domain model changes.
- Refer to ADRs in `docs/adr/` for historical decisions and architectural guidance.
- Keep `CONTEXT.md` updated as domain models or core concepts evolve.
